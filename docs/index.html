UI design, fluid spring motion & anti-slop craft for AI agents.

Tactile UI (tactile-ui) is an open-source SKILL.md that equips Claude Code, OpenAI Codex, Cursor, Antigravity, and Gemini CLI with concrete CSS craft, OKLCH color systems, interruptible pointer-driven springs, and native React <ViewTransition> choreography. 

npx skills add jaxels1/tactile-ui

Core Capabilities

Anti-Slop Layout & Copy

Breaks generic 3-column template grids, removes AI chrome clichés, and enforces plain-English UI copy.

Defensive CSS & OKLCH

Applies minmax(0, 1fr), subgrid, overflow: clip, nested radii, and perceptual oklch() contrast.

Interruptible Springs

1:1 pointer tracking, live release velocity handoff, rubber-banding, and prefers-reduced-motion fallbacks.

React View Transitions

Shared-element morphs, directional navigation via addTransitionType, and Suspense reveals.

Frequently Asked Questions

Which agents are supported?

Works with any SKILL.md-compatible agent: Claude Code, OpenAI Codex, Cursor, Antigravity, and Gemini CLI.

Does it override existing design systems?

No. It preserves your existing tokens, type scale, and palette unless you are building greenfield or explicitly redesigning.
