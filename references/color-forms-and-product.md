# Color, Form UX & Product Presentation Reference

## Color Wheel & Accent System (`@charles.unemployed`)

1. **Temperature contrast**:
   - **Warm page = cool accent**
   - **Cool page = warm accent**
2. **Use the color wheel intentionally**: Derive accents via color-wheel
   relationships instead of picking favorite colors arbitrarily.
3. **Placement**: *"The accent goes on whatever you're selling."*
4. **Restraint**: *"Less is more, especially with accents."*

## 8 Password & Form UX Techniques

1. **Reward early, punish late**: Show immediate progress as rules are met;
   delay error states until input is finished.
2. **Inline validation**: Catch weak/common passwords (e.g. `Password1!`) inline
   while typing.
3. **Chunking**: Group suggested passphrases (e.g. `Velvet-Moth-Arcade-9`).
4. **Closure**: Close an outline into a full shape when strong, avoiding
   redundant labels.
5. **Continuity**: Use monospace characters so masked dots morph directly into
   letters without shifting width.
6. **Redundancy gain**: Sync subtle audio feedback with visual state changes.
7. **Materiality**: Use privacy/frosted glass over password fields so texture
   has a functional reason.
8. **Anthropomorphism**: Subtle character/mascot reactions (looking away on
   reveal) add memorable delight.

## App Store Screenshot Psychology

### Strava Case Study
- **Mental simulation**: Continuous dusk coastline spanning across screenshots.
- **Authority**: Key award badge (*"Apple Watch App of the Year"*) directly
  under logo.
- **Goal-gradient effect**: Continuous orange route across all 8 screenshots
  leading toward the finish flag.
- **Identity hook**: Real user phrasing (*"If it's not on Strava, it didn't happen"*).
- **Aesthetic-usability**: Consistent low-sun lighting and navy-tinted shadows
  instead of pure black.

### Duolingo Case Study
- **Mere-exposure**: Native green, font, and lesson word-tile UI.
- **Hick's law**: One short headline per screenshot (thumbnails render small).
- **Signature move**: Headlines spelled in interactive lesson word tiles.
- **Social proof**: Specific crowd metric (*"4.7 ★ from 5.6M ratings"*) under logo.
- **Primacy effect**: Hook, proof, and best feature in the first 3 screenshots.
- **Distinctive voice**: Memorable, playful mascot expressions.

## Vibecoding Libraries & Visual Tooling

- **Spark** — In-browser 3D scans + dust-dissolve scroll effects.
- **Canvas UI** — HTML shader effects (glass shatter, flames, ASCII/dithered 3D).
- **Pretext** — Cheng Lou's text layout library wrapping text around moving shapes.
- **Pokémon Cards CSS** — 3D tilt holographic foil cards adaptable for welcome/pricing cards.
- **ShaderGradient** — Grainy animated gradient editor exporting to React/Framer.
- **Higgsfield MCP** — Pair **GPT Image 2.6** (frames) + **Seedance 2.5** (animation).
- **Graphic Inspo**: Study vintage/retro print & poster styles (Y2K Sony ads, Mexico '68 optical art, Patrick Nagel, Googie style, Koichi Sato).
